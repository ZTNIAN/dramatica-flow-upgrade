# 修改前后对比 — 场景描写

## 修改前（AI味重）

首先，这是一个雨夜。主角站在窗前，看着窗外的雨。他感到很孤独，因为三年前他的妻子去世了。众所周知，失去亲人是一件很痛苦的事情。

窗外有棵树，树上有只乌鸦在叫。首先，乌鸦叫了三声；其次，主角注意到了；最后，他感到很害怕。

## 修改后（去AI味）

雨下得太久了。

久到墙壁都在渗水，一滴一滴，像是房子在哭。老张头本来已经睡了——说是睡，其实就是躺在那张吱呀作响的木板床上，睁着眼数天花板的裂缝。

所以半夜两点被吵醒，他一点都不意外。但这次的动静不一样。

窗外那棵老槐树上，有只乌鸦在叫。不是正常的叫，是那种——怎么说呢——像是被什么东西掐住了脖子，一声，又一声，断断续续的。

老张头翻了个身，用被子蒙住头。

乌鸦还在叫。这次更近，像是就在窗户外头。

## 对比分析

| 维度 | 修改前 | 修改后 |
|------|--------|--------|
| 机械词 | "首先/其次/最后" | 无 |
| AI过渡词 | "众所周知" | 无 |
| 情感表达 | "感到很孤独"（直接说） | "睁着眼数天花板的裂缝"（展示） |
| 细节 | "有棵树，树上有只乌鸦" | "老槐树"、"被掐住了脖子" |
| 感官 | 只有视觉 | 听觉（叫声）、触觉（被子蒙头） |
| 节奏 | 平铺直叙 | 长短句交错，有呼吸感 |
| 口语化 | 书面语 | "怎么说呢"、"吱呀作响" |
