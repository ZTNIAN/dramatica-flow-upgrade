# Show, Don't Tell

## 核心原则
不要告诉读者人物的感受，展示给读者看。

❌ 他感到很愤怒。
✅ 他捏碎了手中的茶杯，滚烫的茶水流过指缝，但他像没感觉一样。

❌ 她很害怕。
✅ 她的手在发抖，连钥匙都插不进锁孔。试了三遍，才听见那声咔哒。

❌ 他很紧张。
✅ 他在原地转了三圈，深吸一口气，推开门——

## 转换三步法

1. 找出"感到XX" → 找文中所有直接说感受的地方
2. 问"怎么表现的" → 他会做什么？身体有什么反应？
3. 写具体动作 → 把抽象感受变成具体动作和细节

## 常用转换表

| Tell | Show |
|------|------|
| 他很生气 | 摔门/捏碎杯子/声音发抖 |
| 她很害怕 | 往后退/手心出汗/不敢看 |
| 他很累 | 瘫在椅子上/连手指都不想动 |
| 她很伤心 | 盯着发呆/眼泪掉下来 |
| 他很紧张 | 转圈/深呼吸/手指敲桌子 |
| 她很兴奋 | 说话变快/眼睛发亮/坐立不安 |
